# Complexity notes

| Component | Operation | Cost |
| --- | --- | --- |
| Indexed priority queue | push/decrease/pop | O(log V) |
| Dijkstra route planning | shortest path | O((V + E) log V) |
| Trie | prefix lookup | O(p + r) |
| Union-find | component merge | near O(1) amortized |
| LRU cache | get/set | O(1) |
