# Changelog

All notable changes to BitRealm are documented here.

## 1.0.0 -- initial release

- Five-stage campaign: Whispering Caves, Iron Bastion, Spire of Logic,
  Hall of Shadows, Lair of the Bit Dragon.
- Nine bitwise weapons: AND, OR, XOR, NOT, SHL, SHR, ROTL, set, clear.
- Enemy shield mechanic implemented with masked bitfield splice.
- Binary Lock-Pick minigame using `toggleBit`.
- Persistent high-score table (`scores.txt`).
- Cross-platform build: `Makefile` (POSIX) + `build.bat` (Windows).
- ANSI-coloured bit-bar UI with Windows VT opt-in.
- Tutorial covering binary representation and every operator.
