# Complexity reference

| Component | Main operation | Complexity |
| --- | --- | --- |
| Heap | push / pop | O(log n) |
| AVL tree | insert / contains | O(log n) |
| Union-find | find / unite | O(alpha(n)) amortized |
| Merge sort | sort | O(n log n) |
| Dijkstra | shortest paths | O((V + E) log V) |
| KMP | search | O(n + m) |
