# Contributing

Please keep changes focused on a reproducible detection behavior. Add a test that
demonstrates the behavior and run the full standard-library suite before proposing
a change. New language rules should include examples of identifiers, strings,
comments, and line positions. New scoring rules should include both positive and
negative examples, because false positives matter as much as missed matches.

This is an educational and review-support project. Explain heuristic limitations
in user-facing docs, keep output deterministic, and do not add remote upload
behavior for submission files. For larger features, start with an issue describing
the intended dataset and evaluation method.
