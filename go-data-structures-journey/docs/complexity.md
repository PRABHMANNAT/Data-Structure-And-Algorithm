# Complexity reference

| Structure | Typical lookup | Typical insert | Typical removal |
| --- | ---: | ---: | ---: |
| Stack / queue | O(n) | O(1) | O(1) |
| Hash map | O(1) | O(1) | O(1) |
| Binary search tree | O(log n) average | O(log n) average | O(log n) average |
| Binary heap | O(1) peek | O(log n) | O(log n) |

Choose a structure by the dominant operation, not only by its name.
