# Operation guide

| Structure | Representative operation | Typical cost |
| --- | --- | --- |
| Dynamic array | append | amortized O(1) |
| Linked list | prepend | O(1) |
| Hash map | lookup | average O(1) |
| Binary search tree | search | O(h) |
| Binary heap | push/pop | O(log n) |
| Graph | breadth-first search | O(V + E) |
| Trie | lookup | O(k) |
| Disjoint set | union/find | near O(1) amortized |
