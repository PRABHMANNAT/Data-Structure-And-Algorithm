# Complexity reference

| Topic | Representative operation | Complexity |
| --- | --- | --- |
| Stack / queue | push, pop, enqueue, dequeue | O(1) |
| Binary heap | push / pop | O(log n) |
| AVL tree | insert / lookup | O(log n) |
| Trie | insert / lookup | O(L) |
| Union-find | union / find (amortized) | O(alpha(n)) |
| Merge sort | sort | O(n log n) |
| Dijkstra | binary heap implementation | O((V + E) log V) |
| KMP | search | O(n + m) |
