# Learning path

1. Start with stacks, queues, and linked lists to understand invariants.
2. Study heaps and union-find before using them in graph algorithms.
3. Compare the sorting implementations and verify their complexity claims.
4. Practice breadth-first search, depth-first search, and Dijkstra on graphs.
5. Finish with dynamic programming and string matching.

Use `go test ./...` after changing an implementation; tests deliberately cover
edge cases such as empty inputs and duplicate values.
